Multi-Layered Posture Evaluation

CyberLens evaluates defensive controls across five critical web engineering layers:

  • TLS / SSL Cryptography (25%): Certificate validity, expiration window, CA chain, signature algorithms, and TLSv1.2/1.3 protocol negotiation.
  • HTTP Security Headers (35%): HSTS, Content Security Policy (CSP), X-Frame-Options, X-Content-Type-Options, Referrer-Policy, COOP, and CORP.
  • Cookie Defense (15%): Validation of Secure, HttpOnly, and SameSite attributes across session and application cookies.
  • DNS & Email Security (15%): SPF records, DMARC policies at _dmarc, CAA certificate authority authorization, and DNSSEC keys.
  • Infrastructure Exposure (10%): Port 80 to 443 automatic redirection and Server/X-Powered-By software version masking.
